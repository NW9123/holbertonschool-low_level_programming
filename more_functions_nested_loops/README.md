# C - More functions, more nested loops

Introductory C project covering more functions and nested loops.

## Tasks

- `0-isupper.c`: `_isupper` checks for an uppercase character.
- `1-isdigit.c`: `_isdigit` checks for a digit (`0` through `9`).
- `2-mul.c`: `mul` multiplies two integers.
- `3-print_numbers.c`: `print_numbers` prints the numbers from `0` to `9`, followed by a new line.
- `4-print_most_numbers.c`: `print_most_numbers` prints the numbers from `0` to `9`, except `2` and `4`, followed by a new line.
- `5-more_numbers.c`: `more_numbers` prints 10 times the numbers from `0` to `14`, followed by a new line.
- `6-print_line.c`: `print_line` draws a straight line of `n` underscores in the terminal, followed by a new line.

## Compilation

```bash
gcc -Wall -pedantic -Werror -Wextra -std=gnu89 _putchar.c 0-main.c 0-isupper.c -o 0-isupper
```
