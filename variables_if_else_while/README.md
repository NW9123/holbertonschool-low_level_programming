# C - Variables, if, else, while

Introductory C project covering variables, conditions and loops.

## Tasks

- `0-positive_or_negative.c`: assigns a random number to `n` and prints whether it is positive, zero or negative.
- `1-last_digit.c`: assigns a random number to `n` and prints its last digit and how it compares to 5 and 0.
- `2-print_alphabet.c`: prints the alphabet in lowercase using `putchar` only.
- `3-print_alphabets.c`: prints the alphabet in lowercase, then in uppercase, using `putchar` only.
- `4-print_alphabt.c`: prints the lowercase alphabet except `q` and `e`, using `putchar` only.
- `5-print_numbers.c`: prints all single digit numbers of base 10 starting from 0.
- `6-print_numberz.c`: prints all single digit numbers of base 10 starting from 0, using `putchar` only and no `char` variable.
- `7-print_tebahpla.c`: prints the lowercase alphabet in reverse, using `putchar` only.
- `8-print_base16.c`: prints all the numbers of base 16 in lowercase, using `putchar` only.
- `9-print_comb.c`: prints all single-digit numbers separated by `, `, using `putchar` only.

## Compilation

```bash
gcc -Wall -pedantic -Werror -Wextra -std=gnu89 0-positive_or_negative.c -o 0-positive_or_negative
```
