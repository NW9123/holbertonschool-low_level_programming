# C - Functions, nested loops

Introductory C project covering functions and nested loops.

## Tasks

- `0-putchar.c`: prints `_putchar`, followed by a new line, using `_putchar`.
- `1-alphabet.c`: `print_alphabet` prints the alphabet in lowercase, followed by a new line.

## Compilation

```bash
gcc -Wall -pedantic -Werror -Wextra -std=gnu89 _putchar.c 0-putchar.c -o 0-putchar
```
